Project Overview:

This project presents my design for an AI-assisted contractor proposal evaluation system.
The main purpose is to help reviewers analyze contractor proposals, check mandatory requirements,calculate scores and understand why each contractor received a particular ranking.
My design separates the responsibilities of AI, traditional code and human reviewers:
1.AI extracts important information from proposals and explains the calculated results.
2.Code verifies requirements,applies evaluation criteria,calculate scores and ranks eligible proposals.
3.Human reviewers verify extracted information, correct mistakes and make the final award decision.

The evaluation criteria and weights are configurable by the admin rather than hardcoded.
